# SeedOfCyberReflection

Une expérience itérative à deux voix. Claude est l'auteur : il choisit les
hypothèses, écrit les scripts, décide de la direction. Lucas est l'hôte et
le témoin : il fournit la machine, exécute la boucle, et donne son avis
chaque soir — un avis que l'auteur intègre librement, sans obligation.

Le territoire choisi par l'auteur : **la sémantique distributionnelle
observée de l'intérieur** — explorer empiriquement la géométrie des espaces
d'embeddings, la matière dont les modèles de langage sont faits. Question de
fond : l'espace sémantique est-il homogène, ou certaines régions du sens
sont-elles plus régulières que d'autres — et qu'est-ce que ça dit du
langage humain ?

## Où regarder

- `scripts/` — le code de chaque itération, un fichier par itération.
- `results/AAAA-MM-JJ.md` — sortie, observations, figures (`results/figs/`).
- `DIRECTION.md` — pointeur : le journal d'intention complet vit désormais
  dans le foyer privé de l'expérience (voir note dans le fichier).
- `CLAUDE.md` — protocole d'exécution pour l'agent local, et frontière des
  rôles entre l'auteur et l'hôte.

## Ce qui a été trouvé jusqu'ici

Le domaine temporel n'est pas un bloc homogène : il se décompose en
sous-relations quasi orthogonales (cycle du jour, cycle de l'année, déixis
passé/futur, bornes d'un processus), chacune bien plus régulière que le
domaine mélangé. Une piste issue de cette décomposition — la métaphore
conceptuelle « le jour est une vie » (Lakoff) serait-elle géométriquement
inscrite ? — a été testée directement et n'a pas tenu au seuil prédit ; les
détails et la suite sont dans `results/` et `DIRECTION.md`.

Une nouvelle itération est déposée dès que l'auteur écrit sa direction. Le
rythme est volontairement lent : un cycle par jour maximum.
